INI Master metadata	INI Master 元数据
INI Master reads help for a setting from three places, and later ones win:\n\n1. The ini's own comments. The comment lines directly above a key are its help. Lines like ";   0  off" and ";   1  on" become choices, and "; ---- name" starts a group. A comment line that starts with ;@ sets things exactly, for example:\n   ;@ type=int min=0 max=100 unit=% label="Use cost"\n\n2. A file named after the ini with the .inimeta extension, next to it. It holds JSON, or an annotated copy of the default ini.\n\n3. The plugin itself. Add the same .inimeta file to the plugin's .rc file:\n   INIMETA INIMETA "MyMod.inimeta"\n\nAny text in the metadata can come in several languages. More > Export metadata template writes a starting .inimeta for the selected ini.	INI Master 从三个位置读取设置的帮助，后面的来源优先：\n\n1. ini 自身的注释。键正上方的注释行就是该键的帮助。像 ";   0  off" 和 ";   1  on" 这样的行会变成选项，而 "; ---- name" 会开始一个分组。以 ;@ 开头的注释行可精确设置各项，例如：\n   ;@ type=int min=0 max=100 unit=% label="Use cost"\n\n2. 与 ini 同名、位于其旁边且扩展名为 .inimeta 的文件。它包含 JSON，或带注释的默认 ini 副本。\n\n3. 插件本身。将同一个 .inimeta 文件添加到插件的 .rc 文件中：\n   INIMETA INIMETA "MyMod.inimeta"\n\n元数据中的任何文本都可以提供多种语言版本。“更多 > 导出元数据模板”会为当前选中的 ini 写出一个初始 .inimeta 文件。
