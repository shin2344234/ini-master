INI Master metadata	INI-Master-Metadaten
INI Master reads help for a setting from three places, and later ones win:\n\n1. The ini's own comments. The comment lines directly above a key are its help. Lines like ";   0  off" and ";   1  on" become choices, and "; ---- name" starts a group. A comment line that starts with ;@ sets things exactly, for example:\n   ;@ type=int min=0 max=100 unit=% label="Use cost"\n\n2. A file named after the ini with the .inimeta extension, next to it. It holds JSON, or an annotated copy of the default ini.\n\n3. The plugin itself. Add the same .inimeta file to the plugin's .rc file:\n   INIMETA INIMETA "MyMod.inimeta"\n\nAny text in the metadata can come in several languages. More > Export metadata template writes a starting .inimeta for the selected ini.	INI Master liest die Hilfe zu einer Einstellung aus drei Quellen, und spätere haben Vorrang:\n\n1. Die Kommentare der INI selbst. Die Kommentarzeilen direkt über einem Schlüssel sind seine Hilfe. Zeilen wie ";   0  off" und ";   1  on" werden zu Auswahlmöglichkeiten, und "; ---- name" beginnt eine Gruppe. Eine Kommentarzeile, die mit ;@ beginnt, legt Dinge genau fest, zum Beispiel:\n   ;@ type=int min=0 max=100 unit=% label="Use cost"\n\n2. Eine Datei neben der INI mit deren Namen und der Endung .inimeta. Sie enthält JSON oder eine kommentierte Kopie der Standard-INI.\n\n3. Das Plugin selbst. Füge dieselbe .inimeta-Datei in die .rc-Datei des Plugins ein:\n   INIMETA INIMETA "MyMod.inimeta"\n\nJeder Text in den Metadaten kann in mehreren Sprachen vorliegen. Mehr > Metadaten-Vorlage exportieren schreibt eine erste .inimeta für die gewählte INI.
